BarTender Template Linking Guide

The system exports ready-to-print CSV files specifically formatted for Seagull Scientific BarTender 2016 / 2019 / 2021 / 2022.

Exported Headers:
Barcode, LotNo, StyleCode, DesignName, Color, Size, ItemType, SetCode, SetRatio, FinishingUnit
  1. In BarTender, open File → Database Connection Setup.
  2. Select Text File / CSV and browse to your downloaded lot export CSV.
  3. Map Barcode object to field Barcode (Code 128 or QR).
  4. Map text fields to StyleCode, Color, Size, and SetRatio.

TSC Thermal Printer (TSPL) Direct Print

Download .prn command files directly generated in native TSPL for TSC printers (TTP-244 Pro, TE200, TX200).

DIRECTION 1

Send file directly to USB or Network IP via raw socket: nc 192.168.1.100 9100 < label.prn
